## 💈 Barber Time 

Aplicativo Android desenvolvido como projeto acadêmico (App Developer) e portfólio, com o objetivo de praticar o desenvolvimento de aplicações para dispositivos móveis em Java, criação de interfaces XML e armazenamento de dados com SQLite.

Barber Time é um aplicativo que simula o fluxo básico de um serviço de agendamento de uma barbearia, contando com: criação de conta, login, navegação pelo menu, consulta de serviços e registro de agendamentos no próprio dispositivo.

Nota de Desenvolvimento: este projeto foi desenvolvido com apoio e assistência de ferramentas de Inteligência Artificial (IA) utilizada para aceleração do código, refatoração e estruturação de dados!

## ⚙️ Funcionalidades

- Cadastro de usuário: criação de conta com nome de usuário, e-mail e senha.
- Login: autenticação por meio de nome de usuário / e-mail e senha.
- Menu de navegação: Tela que permite a navegação pelas funcionalidades aplicativo.
- Agendamento: seleção de data e horário, escolha dos serviços desejados e preenchimento de dados do usuário.
- Validação de horários: permite seleção de datas atuais ou futuras e consulta aos horários já ocupados.
- Histórico: permite a visualização de todos agendamentos já feitos por aquele usuário e suas respectivas informações.
- Dados do usuário: tela dedicada às informações do usuário e da conta (somente visualização).
- Armazenamento local de dados: contas, informações e serviços serão armazenados em um banco de dados SQLite local, no próprio dispositivo.

## 🛠️ Tecnologias Utilizadas

- Linguagem Java -> lógica e comportamento de telas e elementos.
- XML -> layouts e recursos visuais.
- Android Studio -> ambiente de desenvolvimento.
- SQLite -> armazenamento local de dados.

## 📱 Principais telas

- Login: acesso ao aplicativo por meio de uma conta existente.
- Cadastro: criação de uma nova conta.
- Menu Principal: acesso às funcionalidades do aplicativo.
- Agendamento: seleção de data, horário, serviços e dados.
- Histórico: consulta aos agendamentos já registrados pelo usuário.
- Dados do Usuário: visualização das informações do usuário.

## 🎓 Objetivo acadêmico

Este projeto foi desenvolvido para exercitar conceitos de desenvolvimento Android, organização de Activities, interfaces XML, navegação entre telas, validação de formulários, autenticação e persistência de dados com SQLite.
