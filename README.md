## Barber Time 📱

Barber Time é um aplicativo barbearia para Android com funcionalidades desenvolvidas em Java e interfaces gráficas criadas a partir de XML, 
projetado para facilitar o agendamento de serviços em barbearias, gerenciamento de cadastro de usuários e histórico de atendimentos.

Nota de Desenvolvimento: este projeto foi desenvolvido com apoio e assistência de ferramentas de Inteligência Artificial (IA)
utilizada para aceleração do código, refatoração e estruturação de dados!

## Funcionalidades

- Autenticação - Telas de Login e Cadastro de usuários.
- Menu de navegação - Tela que permite a navegação pelas funcionalidades aplicativo.
- Historico e Dados - Consulta de histórico de agendamentos passados e gerenciamento dos dados do usuário.
- Banco de Dados Local - Armazenamento e gerenciamento de dados nativamente via SQL / Android.

## Tecnologias Utilizadas

- Linguagem Java
- XML
- Android Studio
- Build: Gradle
